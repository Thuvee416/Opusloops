# Mixer

The **Mix** tab keeps the four voice controls on one touch-friendly surface: Kick, Snare, Bass, and Chords.

## Levels

Drag a voice's slider to change its level. The percentage beside its name shows the saved value. A smaller move is usually enough; the sliders are tuned for direct touch rather than mouse precision.

## Mute

Tap **M** to mute or restore a voice. Muting does not delete its steps, so it is safe for quick comparisons. The same mute state appears in Studio.

## Reset

**Reset mix** restores the initial levels and unmutes all four voices. It does not change the step pattern, tempo, key, or project name.

## While playing

The mixer can be adjusted during playback. Return to the sequencer at any time; transport state and project edits remain intact.

## Output

Opusloops plays through the browser's current media output. Output-device routing, desktop audio-driver selection, external plugin buses, and multi-window mixers are outside the mobile production scope.
