# Opusloops

Opusloops is a touch-first loop studio for phones and tablets. It runs in the browser, uses Web Audio for its built-in sounds, and can be installed as a Progressive Web App (PWA).

[Open the production app](https://thuvee416.github.io/Opusloops-Mobile/){ .md-button .md-button--primary }

## What it is for

Opusloops keeps the first creative pass small and immediate:

1. Tap steps into a pattern.
2. Start playback and listen to the loop.
3. Balance the parts in the compact mixer.
4. Save the project on the current device.

There is no external plugin scanner, desktop window management, or workstation-sized setup flow. Sounds and timing run through browser-native Web Audio.

## Product principles

- **Touch first.** Primary controls are sized and spaced for a thumb.
- **One clear action.** Each surface prioritizes the next meaningful musical decision.
- **Calm by default.** Warm neutrals, restrained motion, and quiet hierarchy keep attention on the loop.
- **Local first.** Projects stay in browser-managed storage on the current device.
