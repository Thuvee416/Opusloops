# Studio agent

Natural-language planning is performed by Amazon Bedrock Nova Pro through the authenticated OPUS AWS API. No model credentials are shipped to the browser. A prompt sends a media-free session snapshot, current selection/view/position, recent conversation, the action catalog, device ranges, and raw source peak/RMS measurements. Audio bytes stay local. Session names and MIDI notes are transmitted to AWS for model inference. Analysis is source peak/RMS, not integrated loudness, listening, or a professional mix-quality guarantee.

The agent can create and manage tracks, returns, scenes, MIDI clips and notes; edit tempo, master gain, loops, clip audio/warp/launch settings, synth/sampler/drum settings, MIDI effects, serial audio effects, sends, mixer automation, regions, time and section markers. Newly created tracks/clips/returns can use unique `$alias` references within one plan. Runtime commands support playback, pause/stop, seek, scene launch, views, project download and default master WAV export. Runtime commands run alone; project changes are atomic and commit one Undo snapshot. Browser file selection, physical audio/MIDI setup and hardware permission prompts remain user actions. Other unsupported operations are not available through the catalog and must not be claimed completed.

Each plan is applied to an isolated copy and validated by the studio's project validator before installation. Rejected plans can be repaired twice. Cancellation, session replacement/edits during inference, or invalid plans leave the set unchanged. Undo applies to project edits; playback/downloads are runtime operations. Export uses the real engine, not a model-generated audio file. Current mixing analysis does not perform an automatic rendered-output listening/quality review. Reference-song audio analysis is not implemented; the agent must ask for section details or explain an assumption instead of claiming it listened to a named song.

Sign in through the panel with an existing OPUS account. Existing same-origin legacy OPUS sessions can be reused. New panel sign-in is held in sessionStorage. OPUS account registration remains invitation-based. The API enforces Cognito verification and account membership before inference. DynamoDB counters limit each account to 6 model requests/minute and 100/day, including repair requests. Requests are bounded to 180 KB and responses to 6,000 tokens. Model IAM access is scoped to Nova Pro in us-east-1. No arbitrary code, shell or network tool is exposed.

Implementation tests: `tests/agent-actions.test.cjs`, `tests/studio-agent.cjs`, `infra/aws-backend/tests/studio-agent.test.mjs`. Browser test responses are mocked to test application/Undo/repair deterministically. Real model smoke testing separately established text-to-plan conversion and a three-action new synth track / MIDI bass clip / Arrangement composition. Full authenticated production planning is not covered by those mocks. The historical migration canary helper was retired; do not restore it merely to manufacture test-account access.
